Filters Change the Question

Filters change the question I'm asking.
Pattern #4

Filter = New Question

Question: What happens when I focus on one part of the data?

Recipe: Start broad, apply a filter, then restate the new focused question.

Welcome Back

In Lesson 3, you learned that the shape of your data determines what questions you can ask. Today you're going to learn something that seems small but changes everything: filters.

Most people think filters hide data. That's not wrong — but it's not the right way to think about them. A filter changes the question.

Without a filter: "How many people are in each rank?" With a filter: "How many people in the 129th Wing are in each rank?" Same chart. Same data. Different question. Different answer.

Before We Open Power BI

Look at the question you brought from your Lesson 3 homework. Now write a more specific version — add one constraint.

Examples: "Which rank has the most people?" becomes "Which rank has the most people in the 129th Wing?" — "How many completed training?" becomes "How many TSgts completed training?"

Write your more specific question down. That's what we're answering with a filter today.

Step 1 — Build Your Base Chart

Open Power BI and load your data.

Build a bar chart using the pattern you've practiced:

  1. Select a bar chart.
  2. Place a category column in the X-axis.
  3. Place Name, or another record-identifying field, in the Y-axis.

Make sure the chart answers your original broad question before applying any filters.

Step 2 — Add a Filter

Adding a Filter

Find the Filters panel on the right side of the screen.

Find the column that contains your constraint — the thing you want to focus on. Drag it into the Filters panel.

A list of values appears. Check the box next to the value you want to focus on. Look at the chart. What changed?

The Shift

Before: your chart answered "All of our people — how are they distributed?"

After: your chart answers "Just the people in [your filter] — how are they distributed?"

The chart looks similar. But the question is completely different. The filter doesn't remove data from your spreadsheet. It focuses the lens.

Step 3 — Try Different Values

Keep your chart. Uncheck the value you selected. Check a different value. What changed? Now check both values at once. What changed again? You just asked three different questions using the same chart.

Page-Level Filters

Filtering the Whole Page

Find the Filters panel. Look for "Filters on this page." Drag a column into it. Check a value. Now look at every chart on your page — they all changed. One filter. Every visual. Same focus. This is how dashboards work.

Drill #4

▶ The Question Drill

Start with a clean chart. Apply one filter — state the question out loud. Change the filter — state the new question out loud. Remove the filter — state the original question out loud.

Repeat three times. Each time you state the question out loud, you're connecting the filter to the meaning, not just the mechanics.

Spot the Pattern

Choose the Pattern Before You Click

For each scenario, decide which pattern you would use first.

  1. Your commander asks: Which unit has the most overdue training?
  2. Your audience asks: Are we looking at counts or percentages?
  3. You receive a new spreadsheet: You are not sure what questions it can answer.
  4. Your supervisor asks: What does this look like for only the 129th Wing?

Answer key:

  • Scenario 1 → Pattern #1: Group & Count
  • Scenario 2 → Pattern #2: Change the Lens
  • Scenario 3 → Pattern #3: Read the Shape
  • Scenario 4 → Pattern #4: Filter = New Question

Reflection

  1. 01What question did you answer before filtering?
  2. 02What question did you answer after filtering?
  3. 03Which answer was more useful — and why?
  4. 04What would happen if you added a second filter at the same time?
  5. 05Did filtering reveal anything that surprised you?

Challenge

Using your data, find the most useful filter you could apply — and build it. Then find the least useful filter — one that makes the answer meaningless. Build that too. Explain the difference between them.

Teach Back

Explain what a filter actually does to a chart. Explain why "filters change the question" is more useful than "filters hide data." Explain how a page-level filter works. Use your actual data as the example.

Common Mistakes

Mistake 1 — Filtering before knowing the question

Always write the question first. Then filter. Clicking into the filter panel without knowing what you're focusing on is just clicking.

Mistake 2 — Forgetting the filter is on

You apply a filter, build three more charts, share the report — and everything is scoped to a value no one else knows about. Always check your filters before sharing.

Mistake 3 — Filtering down to meaningless groups

If your filter results in two rows, ask whether the chart is still telling you something real. Small groups produce unstable patterns.

Mistake 4 — Using filters when you should use slicers

Filters require you to set them before sharing. In Lesson 6, you'll learn slicers — visible on-screen filters your audience controls themselves.

Homework

Ask: what is the most useful filter I could apply to my data — and why? Apply it in Power BI. Build one chart that answers a focused question using that filter. Save the file. You'll use it in Lesson 5.

Lesson Summary

Before this lesson, filters removed data.

After this lesson, filters change the question. You're no longer asking "what do I want to hide?" — you're asking "what do I want to focus on?"

In Lesson 5, you'll learn that sometimes the most powerful answer isn't a chart at all. Sometimes it's a single number.
