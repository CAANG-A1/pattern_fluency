Pattern Review

Pattern #3 (Read the Shape) taught you to identify what your data can and cannot answer. Today's pattern takes the next step: when you find a question the data can't answer, you engineer a solution. You don't accept the gap — you close it.

Before We Open Power BI

Find Your Gap

Write down a question that your current data cannot answer. This is the question for this lesson.

Common gaps in military and government data:

"How long does it take from request to approval?" — requires a start date and an end date, not just one date.

"What percentage of our training is overdue, not just incomplete?" — requires a deadline date compared to today.

"Which people appear in our personnel roster but not in our training records?" — requires finding what's missing between two tables.

Write your gap question down. That's the problem this lesson solves.

Three Types of Gaps — and How to Close Them

Most data gaps fall into one of three categories.

Gap Type 1 — Missing Calculation

The data exists. The calculation hasn't been created yet.

Solution: Pattern #11 (Derive the Answer). Write the calculation in plain English. Create a measure.

Example: "Days since last training" — both the training date and today's date exist. The calculation TODAY() - MAX(Training[Date]) closes the gap.

Gap Type 2 — Missing Column

The data is there but not in the right shape. You need a column that doesn't exist yet.

Solution: Create a calculated column or transform the data in Power Query.

Creating a Calculated Column

In the field list, right-click the table that needs the new column.

Choose New column.

Write a DAX formula. Example — to flag overdue training:

Overdue = IF(Training[Status] = "Incomplete" && Training[DueDate] < TODAY(), "Overdue", "Not Overdue")

Press Enter. The new column appears in the table and can be used in visuals immediately.

Gap Type 3 — Missing Connection

The answer requires data from a source that isn't in Power BI yet.

Solution: Add the missing data source and create a relationship using Pattern #9 (Connect the Tables).

Example: "Which people are in Personnel but not in Training?" — requires both tables and a way to find the non-matching rows.

Finding What's Missing Between Two Tables

With both tables connected via a relationship, build a table visual.

Add Name from Personnel to the table.

Add Status from Training to the table.

Filter Status to show only blank values (people with no matching training record).

The result: a list of people who exist in Personnel but have no entry in Training.

That gap was invisible before both tables were connected.

What You Just Learned

You may think you just learned advanced DAX. You didn't. You learned your fifteenth Pattern Fluency pattern. When a question can't be answered, you diagnose why: missing calculation, missing column, or missing data source. Then you apply the right tool to close the gap. The question drives the solution — not the other way around.

Pattern #15

Close the Gap

Question: How do I answer a question my current data doesn't support?

Recipe:

  • Write the question that can't be answered.
  • Diagnose the gap: is it a missing calculation, a missing column, or a missing data source?
  • Missing calculation → Pattern #11: create a measure.
  • Missing column → create a calculated column using a DAX IF or date formula.
  • Missing data source → Pattern #9: import it and connect it.
  • Test: can you now answer the question?

Example: "Which people are overdue — not just incomplete?" → Missing column. Create: IF(Status = "Incomplete" AND DueDate < TODAY(), "Overdue", "Current"). Build the chart. Answer the question.

Drill #15

▶ The Gap Diagnosis Drill

Write three questions that your current data cannot answer. One for each gap type: missing calculation, missing column, missing data source.

For each question, diagnose the gap type out loud: "This is a missing ___ gap."

For the missing calculation: write the plain English sentence and create the measure.

For the missing column: write the DAX formula and create the calculated column.

For the missing data source: identify what file or system contains the missing data.

Close at least two of the three gaps before moving to the reflection.

Common Mistakes

Mistake 1 — Accepting gaps as permanent

"Our system doesn't track that" is often the beginning of a conversation, not the end of one. Data gaps are solvable engineering problems, not permanent limitations. Ask who tracks the missing data and whether it can be exported.

Mistake 2 — Creating a calculated column when a measure is better

Calculated columns store values for every row — they increase the model size. Measures calculate dynamically and adjust to filters. When in doubt, use a measure. Use calculated columns only when you need the result to appear as a field that can be used in hierarchies or relationships.

Mistake 3 — Not testing the gap closure

After closing a gap, verify manually that the answer is correct. Count the overdue rows by hand. Compare to the visual. If they don't match, the DAX is wrong — not the expectation.

Mistake 4 — Building solutions to questions nobody asked

Close gaps that answer real questions. Don't engineer elaborate solutions to hypothetical questions. Let the decision-maker's actual needs drive the engineering.
