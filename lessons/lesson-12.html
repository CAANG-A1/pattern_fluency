Drill Down, Not Just Across

Before This Lesson
Charts show one level of detail. If I want more, I build another chart.
→
After This Lesson
Charts can reveal layers. One chart can answer the summary question and the follow-up question.

Welcome Back

Lesson 11 taught you to calculate numbers that don't exist in the data yet. Now you have measures. You have trends. You have connected tables.

Today you'll learn to go deeper into the data without building more charts.

Most reports show summary numbers. But the most useful questions often start with a summary and then ask: why? What's driving this number? Which specific part of the group is pulling the average down?

In Power BI, you answer those questions by drilling down.

Pattern Review

Pattern #4 (Filter = New Question) taught you to focus on one part of the data. Drilling down is similar — but instead of filtering before you look, you explore layers after you see the summary. You start broad and let the data guide you to the detail.

Before We Open Power BI

Think about a summary number that made you want to ask a follow-up question.

"Unit 129 has 40% incomplete training" — but which ranks? Which specific training? When did it happen?

That follow-up question is the drill-down.

Write your summary question and your follow-up question before opening Power BI.

Step 1 — Build a Hierarchy

A hierarchy is a set of levels you can drill through — from broad to specific.

Example: Year → Month → Week. Or: Wing → Unit → Person. Or: Category → Subcategory → Item.

Creating a Hierarchy in the Field List

In the field list on the right, find a field you want to be the top level. For example, Unit.

Right-click Unit → Create hierarchy.

A new item appears: "Unit Hierarchy."

Now find the next level field — for example, Rank. Right-click it → Add to hierarchy → select "Unit Hierarchy."

You now have a two-level hierarchy: Unit → Rank.

Drag this hierarchy to the X-axis of a bar chart. Add Name (Count) to the Y-axis.

Step 2 — Drill Down

Going Deeper

Look at the chart. You should see a summary at the Unit level.

At the top right of the chart, find the drill-down controls — small arrows pointing up and down.

Click the ↓ (drill down) button to enable drill mode.

Now click on a specific bar — for example, Unit 129.

The chart changes to show Unit 129 broken down by Rank.

You just drilled from Wing level to Rank level with one click.

Click the ↑ (drill up) button to return to the summary view.

If the Drill Controls Don't Appear

Hover your mouse over the chart. The drill controls appear in the top right corner — small arrow icons. If you still don't see them, click on the chart first to select it. The controls only show when the chart is selected and has a hierarchy on the axis.

What Just Happened

You answered two questions using one chart. The first question was at the Unit level — which unit has the most people? The second question was at the Rank level — within that unit, how are they distributed by rank?

You didn't build a second chart. You drilled into the first one.

What You Just Learned

You may think you just learned how to drill down. You didn't. You learned your twelfth Pattern Fluency pattern. When a summary number raises a follow-up question, build a hierarchy and drill. The chart becomes a tool for exploration, not just display.

Pattern #12

Drill to the Detail

Question: What's hiding underneath the summary number?

Recipe:

  • Write the summary question and the follow-up question.
  • Create a hierarchy in the field list: right-click the top-level field → Create hierarchy → add sub-levels.
  • Drag the hierarchy to the X-axis.
  • Enable drill mode using the arrow controls on the chart.
  • Click a specific bar to drill down into that category.
  • Click the up arrow to return to the summary.

Example: Unit hierarchy → click Unit 129 → see breakdown by Rank. Click the up arrow → return to all units.

Drill #12

▶ The Exploration Drill

Build your hierarchy chart. Start at the summary level.

State out loud: "At this level, the question is ___."

Drill down into one bar. State out loud: "At this level, the question is ___."

Drill back up. State the summary question again.

Drill into a different bar. State the question at the detail level.

Repeat three times with different starting bars. Each time, state the question — because each bar is a different focused question.

Reflection

  • 01What was the summary question? What was the follow-up question?
  • 02Did drilling down reveal anything surprising in your data?
  • 03When would you use drill-down instead of Pattern #4 (Filter = New Question)?
  • 04What third level could you add to your hierarchy to go even deeper?
  • 05Which level of detail is most useful for your audience — and does the right level depend on who's asking?

Challenge

Using your own data, create a three-level hierarchy.

Write the question at each level before you build anything:

Level 1 question: ___. Level 2 question: ___. Level 3 question: ___.

Build the chart. Drill through all three levels.

Show it to one person. Let them drill themselves. Ask: "What did you discover that surprised you?"

Teach Back

Explain what a hierarchy is and why it's useful.

Explain the difference between drilling down and filtering.

Explain Pattern #12 in plain language:

When a summary number raises a follow-up question, build a hierarchy and let the reader explore the detail without leaving the chart.

Common Mistakes

Mistake 1 — Building a new chart for every level

Some analysts build a separate chart for each level of detail — one for units, one for ranks, one for individuals. That's the old way. Hierarchies and drill-down replace all three with one interactive chart.

Mistake 2 — Forgetting to enable drill mode

Clicking a bar without enabling drill mode selects and filters the chart — it doesn't drill down. You must click the drill arrow first, then click the bar. The order matters.

Mistake 3 — Too many hierarchy levels

Three levels is the practical maximum for most audiences. Beyond that, the exploration becomes exhausting rather than useful. Know which levels your audience actually needs.

Mistake 4 — Using drill-down when filtering is better

If your audience only ever needs to see one level — for example, always rank-level, never unit-level — a hierarchy is unnecessary complexity. Use Pattern #4 (Filter = New Question) instead.

Homework

Find a real question in your work that has a natural summary level and a detail level.

Build a hierarchy and a drill-down chart for it.

Show it to your supervisor or a coworker. Let them explore. Write down what they discovered.
