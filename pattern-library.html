Pattern Library

Why This Page Exists

Power BI is not just a collection of buttons. It is a set of repeatable patterns. When you recognize the pattern, you know what to do next.

Pattern #1

Group & Count

Use when: You need to know how many records are in each category.

Recipe: Category → X-axis. Record identifier → Y-axis.

Pattern #2

Change the Lens

Use when: The same data may need a different visual to answer a different question.

Recipe: Keep the data the same. Change the chart type. Ask what became easier or harder to see.

Pattern #3

Read the Shape

Use when: You receive data and need to know what questions it can support.

Recipe: Identify category columns, identify number columns, then identify possible and impossible questions.

Pattern #4

Filter = New Question

Use when: You want to focus the answer on one part of the data.

Recipe: Start with a broad chart. Apply a filter. Restate the focused question.

Pattern #5

One Number Answer

Use when: One number answers the most important question in the room.

Recipe: Build a card, verify the calculation, then read it as a sentence.

Pattern #6

Design for the Reader

Use when: Your report needs to be understood by someone who did not build it.

Recipe: Plain-English labels, logical layout, intentional color, and useful slicers.

Pattern #7

Publish, Test, Improve

Use when: Your report needs to leave your computer and be used by another person.

Recipe: Publish, test, share, ask what the report communicates, then improve it.

Pattern #8

Build the Full Loop

Use when: You are ready to turn a real question into a useful report.

Recipe: Question → Data → Visuals → Design → Publish → Feedback → Present.

Spot the Pattern Practice

Scenario Practice

Scenario: Your commander asks, "Which unit has the most overdue training?"

Start with: Pattern #1, Group & Count. Then use Pattern #3 to confirm the data supports the question, and Pattern #4 if you need to focus on one training type.

Scenario: Your audience already knows totals, but they are arguing about percentages.

Start with: Pattern #2, Change the Lens.

Scenario: You open a spreadsheet and cannot tell what questions it can answer.

Start with: Pattern #3, Read the Shape.
