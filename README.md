# Pattern Fluency: Power BI

A complete Power BI training curriculum built on the Payam Method of instruction.

## Structure

```
index.html              — Home / lesson index
philosophy.html         — The Pattern Fluency Method explained
reference.html          — Quick reference card
css/style.css           — All styles
js/main.js              — Navigation and interactivity
lessons/
  lesson-1.html         — Answer Your First Question
  lesson-2.html         — Different Pictures Tell Different Stories
  lesson-3.html         — Your Data Has a Shape
  lesson-4.html         — Filters Change the Question
  lesson-5.html         — One Number Tells a Story
  lesson-6.html         — Make It Yours
  lesson-7.html         — Share What You See
  lesson-8.html         — Capstone
```

## Hosting on GitHub Pages

1. Create a new GitHub repository
2. Upload all files preserving the folder structure
3. Go to Settings → Pages → Source → Deploy from branch → main → / (root)
4. Your site will be live at: `https://[your-username].github.io/[repo-name]/`
